# 沉浸式翻译&学习 V0.9.2

## 重点更新
- 新增“翻译服务池”：可同时保存多个 API，拖拽决定调用优先级。
- 某个服务失败、超时、限流时自动尝试下一家。
- 专业 NMT 可参与正文翻译；词典、词根、例句等结构化学习任务自动选择优先级最高的大模型。
- 内置大模型预设：DeepSeek、OpenAI、Qwen、GLM、豆包、SiliconFlow、OpenRouter、Gemini、Claude、OpenAI-Compatible。
- 内置 NMT 预设：DeepL、阿里云机器翻译、火山引擎机器翻译、腾讯云兼容适配器。
- 每个服务可单独启用/禁用、测试连接、设置超时。
- 扩展更新后旧网页不再直接显示 Extension context invalidated，而是提示“立即刷新”。
- 长 UI 标题译文解除 line-clamp 裁切，尽量完整显示。

## 路由规则
1. 正文翻译：严格按服务池从上到下尝试 NMT / LLM。
2. 查词、音标、词根、例句：自动跳过 NMT，仅按顺序使用 LLM。
3. 如果前面的接口 429、超时或报错，会短暂降级并尝试后面的接口。

## 腾讯云说明
腾讯云 2026 年公开 API 文档已从 API 概览中移除旧 `TextTranslate` 条目；本版仍提供可编辑 Endpoint / Action / Version 的兼容适配器给存量账号使用。请先点“测试连接”，测试成功后再放到高优先级。


## V0.9.1
- “添加翻译服务”不再使用浏览器原生 prompt。
- 改成真正可点击的服务选择面板。
- 支持按“专业 NMT / 大模型”分类浏览。
- 支持搜索 DeepL、DeepSeek、阿里云、Qwen 等。
- 点击卡片即可添加；同一种服务可添加多组不同账号/模型配置。
- 已经添加过的服务会显示“再加一组”，方便多 API Key / 多模型并存。


## V0.9.2
- 产品名称正式改为 **沉浸式翻译&学习**。
- 后续版本继续沿用该名称。
